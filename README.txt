HOW TO GET THE JAR (GitHub, no installs):
1. Create a free repo on github.com (New repository).
2. Upload ALL files from this folder (including the hidden .github folder).
   Easiest: install GitHub Desktop, or on the repo page use "Add file > Upload files"
   and drag the contents in (make sure .github/workflows/build.yml is included).
3. Open the "Actions" tab. Wait for "Build Revive" to finish (green check).
4. Click the run, scroll to "Artifacts", download "revive-mod". Unzip it: the .jar inside is the mod.
5. Put that jar in mods/ on the SERVER and on every CLIENT, with Fabric API.
